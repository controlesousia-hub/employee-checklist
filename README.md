# Checklist Départ/Arrivée Employé

Application mobile PWA professionnelle pour la gestion des checklists d'arrivée et de départ d'employés (RH, IT, Manager).

## Instructions d'installation

1. Décompresser le projet
2. Ouvrir le terminal dans le dossier du projet
3. Exécuter `npm install`
4. Copier `.env.example` en `.env` et ajouter vos clés Supabase
5. Lancer l'application : `npm start`
